# Package List 低保真结构

> Package List 是 V1 最关键的批量决策页。它必须让用户在约 10–20 个 Package 中完成盘点，而不是逐个进入详情页才能知道能否合箱。

### Card 最小信息

| 信息 | 为什么保留 | 显示规则 |
| --- | --- | --- |
| 国内运单号的可辨识末位 | 用户用来和电商订单核对 | 默认脱敏显示；完整号仅在详情中按需要查看。 |
| 商品来源或最小商品信息 | 帮助用户区分相似 Package | 来自预报；无可靠信息时显示“已预报，待 Warehouse 匹配”，不编造商品名称。 |
| 用户可理解的状态 | 决定能否选择、是否要等待或处理 | 使用状态文案，不显示内部状态码。 |
| 最近事件 / 更新时间 | 让用户判断状态是否有新进展 | 只显示最相关的一条，不展示冗长事件日志。 |
| 异常或关联 Shipment 提示 | 避免遗漏或重复选择 | 有异常显示影响；已转运显示 Reference 与跳转入口。 |

**不在列表默认显示：** 最终重量、费用、完整历史物流、照片和大量订单字段。这些信息在当前批量决策中不能帮助判断是否可合箱，且会降低 10–20 件列表的扫描效率。

## Filter

固定的状态筛选以“数量 + 用户语言”呈现：

| 筛选 | 包含对象 | 用户问题 |
| --- | --- | --- |
| 全部 | 所有当前用户拥有的 Package | 我一共有哪些 Package？ |
| 待到仓 | 已预报、送往 Warehouse 中 | 哪些还没到？ |
| 待确认 | 已物理到仓但尚在确认归属 / 可处理性 | 哪些到了但还不能合箱？ |
| 可合箱 | 已确认归属且无阻塞问题 | 我现在可以选择哪些？ |
| 已转运 | 已属于有效 Shipment | 哪些已经不能再选？ |
| 需处理 | Package Exception | 哪些会阻塞我？ |

- 选择一个筛选后保持该集合的数量；从 Home 跳入时预选对应筛选。
- 默认排序：需处理 → 可合箱 → 待确认 → 待到仓 → 已转运。每组内按最近状态更新排序。
- 筛选不是搜索能力；按完整单号搜索不属于当前冻结 P0。

## Selection Mode

点击“开始合箱”后，只能从 **可合箱** 集合多选。其他 Package 仍可见，但不可勾选且必须说明原因。

```text
┌──────────────────────────────────┐
│ ‹ 选择本次要转运的 Package         │
│ 已选择 8 件                        │
│ 可合箱但未选择 2 件                │
├──────────────────────────────────┤
│ ☑ 国内单号 •••• 4821  已确认归属   │
│ ☑ 国内单号 •••• 6173  已确认归属   │
│ ...                                │
│ ☐ 国内单号 •••• 4018  已确认归属   │
│ ☐ 国内单号 •••• 9226  已确认归属   │
│ ──────────────────────────────── │
│ 🔒 国内单号 •••• 2095              │
│    已到仓，正在确认归属，暂不可选   │
│ 🔒 国内单号 •••• 1008              │

├──────────────────────────────────┤

│ [继续创建 Shipment]                │
└──────────────────────────────────┘
```

### 选择规则

| 项目 | 规则 |
| --- | --- |
| 可选择 | 仅“可合箱” Package；至少选择 1 件才可继续。 |
| 不可选择 | 待到仓、待确认、需处理、已加入有效 Shipment 的 Package。 |
| 不可选原因 | 行内显示“等待到仓”“正在确认归属”“请先处理问题”或“已加入 REF-••••”；可点击进入详情。 |
| 防遗漏反馈 | 固定底栏同时显示“已选择 N 件”和“可合箱但未选择 M 件”；M 大于 0 时仅提醒，不阻止提交。 |
| 返回 | 返回前保留当前勾选；用户主动放弃时才清空选择并二次确认。 |
| 继续 | 进入 Shipment Creation 的确认页；此时仍是草稿，Package 尚未最终锁定。 |

## Package Detail 的低保真职责

P02 不增加新的批量操作。用户点击 Card 后看到：

```text
┌──────────────────────────────────┐
│ ‹ Package 详情                    │
│ 国内单号 •••• 4821                 │
│ [可合箱] 已确认归属                │
├──────────────────────────────────┤
│ 最近状态：Warehouse 已确认归属     │
│ 预报信息：订单截图 / 最小商品信息  │
│ 到仓与归属事件                     │
├──────────────────────────────────┤
│ 相关 Shipment（如已加入）          │
│ [查看 Shipment REF-••••]          │
└──────────────────────────────────┘
```

Exception 时，详情将状态说明、影响与“按指引补充信息”置于事件记录之前；用户只能按明确指引更正必要信息，不提供无边界的通用编辑入口。

## Empty State

| 场景 | 表达 | 行动 |
| --- | --- | --- |
| 无 Package | 说明“国内下单后，预报运单号以便 Warehouse 匹配” | 新增预报 |
| 无可合箱 Package | 说明现有 Package 分别在等待到仓 / 确认；不显示无效的“开始合箱” | 查看待到仓或待确认筛选 |
| 筛选无结果 | 说明该状态暂无 Package，保留筛选切换 | 切换筛选 |
