# 产品假设池与验证计划

> 本表中的内容全部起源于 **Product Assumption**，不是市场数据或行业事实。P01 探索性访谈已为其中部分假设提供单样本证据，但不构成广泛验证；当前判定与边界见 [hypothesis-validation.md](hypothesis-validation.md)。A01–A09 与 [08-validation-plan.md](08-validation-plan.md) 使用同一编号。

| ID | Product Assumption | 为什么需要这个假设 | 风险 | 实际项目如何验证 |
| --- | --- | --- | --- | --- |
| A01 | 用户存在多 Package 集运需求 | 合箱是候选核心闭环的前提 | 可能大多数用户只寄单件，或已用其他方式解决 | 复盘最近一次寄送：包裹数量、来源、到仓时间、是否合并、为何合并/不合并 |
| A02 | 用户需要主动预报国内包裹 | 影响产品起点与包裹归属/匹配方式 | 实际仓库可能有其他匹配机制，预报未必必要 | 与服务方/仓库确认匹配流程；询问用户是否曾预报、漏报或错配 |
| A03 | 用户希望统一查看多个 Package 状态 | 支撑 Package 管理、到仓确认和可操作状态设计 | 用户可能主要依赖国内快递或客服，统一视图价值不足 | 让用户回放查询路径、查询频率和不确定时的处理方式；测试状态信息理解度 |
| A04 | 合箱是核心操作 | 决定多 Package → 一次 Shipment 是否应是 MVP 主任务 | 合箱可能是偶发动作，或由人工轻易解决 | 访谈复盘合并/不合并决策，识别频率、触发条件、约束和替代方案 |
| A05 | 用户关心最终计费重量和报价 | 支撑仓库处理、报价信息和支付决策顺序 | 用户可能只关心总价，或实际服务采用固定价/预付款模式 | 获取真实报价/结算样本（如可得）；询问用户真实付款时点和价格判断方式 |
| A06 | 用户需要清晰了解支付后何时出库 | 决定支付状态与履约状态是否必须分层表达 | 实际业务可能先发后付、到付或存在账期，用户未必关心出库时点 | 回放付款后经历；核对可获得的服务规则、支付/出库事件和用户查询行为 |
| A07 | 用户高度关注国际物流状态 | 支撑履约时间线和阶段状态设计 | 用户可能已有足够的承运商追踪工具，或只关心最终签收 | 记录出库后的查询触发、工具、所需事件和客服联系原因；测试最小状态集合理解度 |
| A08 | 异常状态需要明确下一步操作 | 支撑异常信息和支持入口设计 | 异常频率可能低，或用户只愿意人工处理 | 追问真实异常案例；记录影响、用户动作、支持方式和结果；无案例时如实记录 |
| A09 | 微信小程序适合作为主要用户入口 | 决定产品载体、登录、消息与关键任务体验 | 用户可能更依赖网页、客服群、现有 App 或社交渠道 | 访谈工具偏好和情境；任务原型测试；评估相关平台能力是否可获得 |
| A10 | 英国中国留学生、长期居英华人和高频中国电商购买者是值得优先研究的候选人群 | 决定招募范围与初始价值主张 | 三类需求可能不同，甚至都不是最佳首发人群 | 招募三类近期用户，按真实寄送频率、包裹数、任务复杂度和痛点强度比较 |
| A11 | 英国收货地址可在创建 Shipment 时提供，并可在重复使用中复用 | 影响提交要求与地址资产优先级 | 地址可能需在更早阶段验证，或用户低频且地址常变 | 询问地址填写时点、地址数量、复用方式、错误经历及真实规则 |
| A12 | 用户会信任并使用由产品呈现的仓库、报价和物流信息 | 决定时间、来源、信息透明度与模拟边界的表达 | 可信度可能主要来自品牌/客服；演示数据不能代表真实信任 | 访谈用户信任线索；测试信息来源、更新时间和异常说明对理解的影响 |

## 验证优先级

| 优先级 | 假设 | 原因 |
| --- | --- | --- |
| P0 | A01、A04、A05、A06、A07、A09、A10 | 决定是否存在值得解决的核心任务、为谁做、交易/履约顺序是否成立，以及小程序是否是合适入口 |
| P1 | A02、A03、A08、A11 | 决定 Package 归属、状态、异常和地址等能力应如何设计 |
| P2 | A12 | 影响信任和信息质量，但应在核心任务被确认后进一步验证 |

## 验证纪律

- 访谈以“最近一次真实寄送经历回顾”为主线，不以对设想功能的投票替代行为证据。
- 每个结论需记录样本条件、原话/行为证据、反例与限制；小样本只能形成方向性证据。
- 不将竞品页面、常识或单个用户意见写成普遍需求。
- 没有真实承运商、仓库或支付资料时，任何作品集演示数据都需标记为模拟。
