## 填写规则

### 单个样本列

每个 `P0x` 单元只记录简短证据方向，例如：

```text
Supports — 最近一次有 4 件包裹，因等待第 4 件而延后提交；详见 P02
```

或：

```text
Contradicts — 本次仅单件直寄，未发生合箱；详见 P04
```

不得只写“支持/不支持”，必须保留可回溯的具体经历和访谈编号。

### Evidence 列

综合独立样本的共同点、反例与限制，不把 Self Journey 计入独立样本数。示例格式：

```text
P01、P03 有多包裹合并行为；P04 为单件直寄。样本均来自近期个人经历，样本量有限。
```

### Conclusion 列

| 允许值 | 适用条件 |
| --- | --- |
| Supported | 多个独立样本提供具体、方向一致的证据，且存在已记录的反例/范围说明 |
| Partially Supported | 有支持证据，但只适用于部分用户/情境，或存在重要反例 |
| Not Supported | 多个独立样本的具体经历持续不支持该假设；仍需说明样本边界 |
| Insufficient Evidence | 样本不足、没有相关真实经历、证据矛盾或尚未完成访谈 |

在 4–6 名独立样本的个人作品集研究中，即使标记为 `Supported`，也只能表述为“本轮样本支持”，不能扩展为市场普遍结论。
